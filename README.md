# UI/UX Design Knowledge Base

A comprehensive, everything-you-need repository for UI/UX design — principles, patterns, systems, processes, checklists, and resources.

## Structure

| Folder | Description |
|---|---|
| [01-design-principles](./01-design-principles) | Core design principles, color theory, typography, spacing, visual hierarchy, accessibility |
| [02-component-patterns](./02-component-patterns) | Reusable UI component patterns with best practices and examples |
| [03-design-system](./03-design-system) | Design tokens, component libraries, iconography, animation guidelines |
| [04-ux-process](./04-ux-process) | End-to-end UX process: research, wireframing, prototyping, testing, handoff |
| [05-checklists](./05-checklists) | Ready-to-use checklists for UI, UX, and accessibility reviews |
| [06-resources](./06-resources) | Curated tools, books, blogs, and inspiration sources |
| [07-ai-agentic-ux](./07-ai-agentic-ux) | Agentic experience (AX) design, AI interface patterns, agentic design patterns, AI's impact on design practice, service design in the AI era, and AI illustration/motion |
| [08-ai-agent-integration](./08-ai-agent-integration) | Ready-to-use skill/rule files so Claude Code, Cursor, Devin, and Antigravity actually consult this knowledge base while coding |

## How to Use

- **Starting a new project?** Begin with [04-ux-process](./04-ux-process) for the full workflow.
- **Building a component?** Check [02-component-patterns](./02-component-patterns) for patterns and best practices.
- **Setting up a design system?** Start with [03-design-system](./03-design-system) for tokens and architecture.
- **Reviewing your work?** Use the checklists in [05-checklists](./05-checklists).
- **Learning fundamentals?** Read through [01-design-principles](./01-design-principles).
- **Designing an AI/agentic feature?** Start with [07-ai-agentic-ux](./07-ai-agentic-ux).
- **Wiring this repo into Claude Code, Cursor, Devin, or Antigravity?** See [08-ai-agent-integration](./08-ai-agent-integration).

## Who Is This For

- **Developers** who want to build better UIs without a designer
- **Designers** who want a reference and checklist library
- **Product managers** who want to understand UX process and review designs
- **Anyone** learning UI/UX from scratch
