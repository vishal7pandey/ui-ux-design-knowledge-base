# Onboarding AI Features and First-Time UX

First-time UX for AI features is different from regular onboarding. Users need to understand what the AI can do, how to interact with it, and what to expect from the output.

---

## 1. Goals of AI Onboarding

- Set accurate expectations.
- Show the value quickly.
- Teach users how to interact.
- Build trust and confidence.
- Encourage safe exploration.

---

## 2. First Screen

The first screen should answer three questions:

1. **What can this AI do?**
2. **How do I start?**
3. **What are the limits?**

### Examples

- “Meet your AI writing assistant. It drafts, edits, and summarizes. Just start typing or pick a suggestion.”
- “This assistant can answer questions based on your documents. It may make mistakes, so double-check important facts.”

---

## 3. Onboarding Patterns

### Welcome with examples

- Show 3–5 example prompts.
- Use real, useful examples from the product.
- Let users tap to try one.

### Guided first task

- Walk the user through one full AI interaction.
- Show how to enter a prompt.
- Show how to use the output.
- Show how to give feedback.

### Interactive sandbox

- Provide a demo area where users can test safely.
- Use sample data.
- No consequences for mistakes.

### Coach marks

- Highlight the AI input, output, and controls.
- Keep marks short and dismissible.
- Do not overuse.

### Tooltip tour

- Step-by-step tooltips for key parts of the AI interface.
- Let users skip or restart.

### Video or animation

- Show a short, visual example.
- Keep it optional.
- Provide captions and transcripts.

---

## 4. Setting Expectations

- What the AI does well.
- What it does not do.
- When to verify or edit output.
- How the AI uses data.
- How to control or disable the AI.

---

## 5. Building Trust

- Start with low-stakes tasks.
- Show quick wins.
- Be honest about mistakes.
- Provide sources and explanations.
- Let users edit or reject output.
- Make it easy to give feedback.

---

## 6. Progressive Onboarding

- Teach one thing at a time.
- Introduce advanced features after basic ones.
- Use contextual hints as the user explores.
- Do not dump all information at once.

---

## 7. First-Time UX Best Practices

- Keep the first experience short.
- Show value within the first 30 seconds.
- Use plain language.
- Avoid technical AI terms.
- Provide exit and skip options.
- Let users revisit onboarding.
- Personalize if relevant and consented.

---

## 8. Common Mistakes

- Overpromising AI capabilities.
- Long onboarding before users can try anything.
- No example prompts.
- Hiding limitations.
- No way to skip or go back.
- Anthropomorphizing the AI.
- No first-time value.
- Not explaining data use.

---

## 9. Checklist

- [ ] First screen explains what the AI can and cannot do.
- [ ] Example prompts guide the first interaction.
- [ ] A quick win is possible within the first session.
- [ ] Users learn how to enter prompts or commands.
- [ ] Users learn how to use, edit, and reject output.
- [ ] Limitations and uncertainty are disclosed.
- [ ] Data use and privacy are explained.
- [ ] Onboarding can be skipped and revisited.
- [ ] Progressive hints appear as users explore.
- [ ] Trust is built through honesty and control.
