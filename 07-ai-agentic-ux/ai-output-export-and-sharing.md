# AI Output Export and Sharing

Users often need to take AI output out of the product. Good export and sharing UX makes that easy, reliable, and secure.

---

## 1. Why Export and Sharing Matter

- Users want to use AI output in other tools.
- Sharing helps collaboration and decision-making.
- Export is a key moment of value for the user.
- The experience reflects on the product’s trustworthiness.

---

## 2. Export Formats

| Format | Use case |
|--------|----------|
| **Plain text** | Simple copying into any tool. |
| **Markdown** | Documents, notes, wikis. |
| **HTML** | Rich content for web. |
| **PDF** | Static, shareable documents. |
| **DOCX** | Word-compatible editing. |
| **CSV / XLSX** | Data and tables. |
| **JSON** | Structured data and code. |
| **Image** | Visuals and diagrams. |
| **Code file** | .py, .js, .css, etc. |

---

## 3. Export Patterns

### Copy

- One-click copy to clipboard.
- Support keyboard shortcuts (Ctrl+C).
- Show a brief confirmation.

### Download

- Let users download in a chosen format.
- Provide filename and location options.
- Show file size and type.

### Save to cloud

- Save to Google Drive, Notion, Dropbox, or other integrations.
- Show destination and permissions.

### Insert

- Insert generated content into the current document or project.
- Place the cursor at the right location.

### Shareable link

- Create a read-only link.
- Control access and expiration.
- Track views or edits.

---

## 4. Sharing Patterns

### Direct share

- Share via email, Slack, Teams, or other apps.
- Include a preview and message.

### Permission control

- View, comment, edit.
- Public, organization, or private.

### Link sharing

- Generate a link.
- Set expiration and password if needed.
- Show who has access.

### Embed

- Embed AI output in another page or tool.
- Keep content synced or static as needed.

---

## 5. Security and Privacy

- Do not expose sensitive AI output publicly.
- Respect permissions and data limits.
- Watermark or mark AI-generated content.
- Track exports where required for compliance.
- Warn users before sharing content with sensitive data.

---

## 6. Best Practices

- Make export easy to find.
- Support common formats.
- Let users choose quality, format, and scope.
- Preserve formatting.
- Include source and metadata if relevant.
- Provide shareable links with clear permissions.
- Confirm successful export or share.
- Allow users to undo or revoke shares.

---

## 7. Common Mistakes

- Only supporting one format.
- Hidden export options.
- Losing formatting during export.
- No permission controls for shared content.
- No way to revoke a share.
- Not warning about sensitive data.
- Export names that are unclear.
- No confirmation after export.

---

## 8. Checklist

- [ ] Export options are easy to find.
- [ ] Common formats are supported.
- [ ] Copy, download, save, insert, and share are available.
- [ ] Formatting is preserved.
- [ ] Permissions are clear and controllable.
- [ ] Shared links can be revoked.
- [ ] Sensitive data is protected.
- [ ] AI-generated content is labeled.
- [ ] Export includes metadata or sources where relevant.
- [ ] Users get confirmation after export or share.
- [ ] Sharing respects privacy and compliance.
