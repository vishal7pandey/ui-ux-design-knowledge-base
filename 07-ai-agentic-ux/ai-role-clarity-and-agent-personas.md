# AI Role Clarity and Agent Personas

AI agents need clear roles and consistent personalities. Role clarity helps users know what to expect. Agent personas make the agent predictable and trustworthy.

---

## 1. Why Role Clarity Matters

- Users need to know what the agent can do.
- Unclear roles lead to confusion and misuse.
- Clear roles set expectations and build trust.
- Roles help the team design consistent behavior.

---

## 2. Defining an AI Role

A clear role statement answers:

- **Who is the agent?** (e.g., a research assistant, a writing coach)
- **What does it do?** (e.g., find, summarize, draft)
- **What does it not do?** (e.g., make decisions, send messages alone)
- **How does it behave?** (e.g., concise, thorough, cautious)
- **When should the user override?** (e.g., high-stakes actions, creative work)

Example:

```
Nova is a research assistant that helps users find, summarize, and fact-check information. It is concise and precise. It does not make decisions or take actions on the user’s behalf.
```

---

## 3. Agent Personas

A persona is a consistent set of traits for an AI agent.

### Dimensions of an AI persona

| Dimension | Examples |
|-----------|----------|
| **Tone** | Friendly, formal, direct, playful. |
| **Verbosity** | Brief, balanced, detailed. |
| **Confidence** | Cautious, assertive, exploratory. |
| **Style** | Professional, casual, technical, empathetic. |
| **Initiative** | Reactive, proactive, balanced. |

### Keep personas aligned with the task

- A coding assistant should be precise and technical.
- A wellness coach might be warm and empathetic.
- A customer support agent should be clear and helpful.

---

## 4. Role Communication

### Name

- Choose a name that is easy to say and remember.
- Avoid names that imply human identity.
- Be consistent across the product.

### Avatar or icon

- Use an icon or visual marker for the AI.
- Do not use realistic human faces.
- Keep the visual consistent.

### Capability statement

- Show what the agent can and cannot do.
- Keep it short and accessible.

### Signature phrase

- A short, consistent way the agent begins or ends messages.
- Example: “Here is what I found:”

---

## 5. Managing Expectations

- Be clear about capabilities on first use.
- Update users if the role changes.
- Provide examples of good prompts.
- Show the agent’s limits.
- Explain when the user should take over.

---

## 6. Persona Consistency

- Use the same tone across the agent’s messages.
- Do not switch between formal and casual unexpectedly.
- Use the same name and avatar.
- Keep the same confidence level unless context changes.
- Document the persona for the team.

---

## 7. Common Mistakes

- No defined role.
- Role that overpromises.
- Inconsistent tone and behavior.
- Anthropomorphizing too heavily.
- Persona that conflicts with the task.
- No communication of the agent’s limits.
- Different names or visuals for the same agent.

---

## 8. Checklist

- [ ] The agent’s role is documented and specific.
- [ ] Capabilities and limits are clear to users.
- [ ] Persona dimensions are defined.
- [ ] Tone, verbosity, and style are consistent.
- [ ] Name and avatar are appropriate and consistent.
- [ ] Capability statement is shown on first use.
- [ ] Examples help users interact with the agent.
- [ ] High-stakes or out-of-scope actions are clearly defined.
- [ ] Persona is reviewed and updated over time.
- [ ] Team follows the persona in all AI copy and behavior.
