# Onboarding and Activation

Onboarding is the process that turns a new user into a successful, activated one. Activation is the moment a user experiences the product’s core value for the first time.

---

## 1. Onboarding Goals

- Help users understand the product’s value.
- Get them to their first success quickly.
- Build confidence and trust.
- Set the foundation for long-term use.

---

## 2. Activation

Activation is the first meaningful outcome the user achieves. It is the “aha” moment when the product proves its worth.

### Examples

| Product | Activation moment |
|---------|-------------------|
| Spotify | User listens to their first song. |
| Slack | User sends their first message. |
| Dropbox | User uploads or shares their first file. |
| Canva | User creates and downloads their first design. |
| Duolingo | User completes their first lesson. |

### Defining activation

Activation is usually defined by:

- A specific action or set of actions.
- Completed within a time window (e.g., first 7 days).
- Strongly correlated with retention.

---

## 3. Onboarding Patterns

### Welcome screen

- Set expectations.
- Show the product’s value proposition.
- Provide a clear first action.

### Progressive disclosure

- Reveal features as the user needs them.
- Avoid overwhelming users with everything at once.

### Contextual tooltips

- Highlight one action at a time.
- Triggered by the user’s first interaction.
- Dismissible and skippable.

### Checklists

- Show a list of setup steps.
- Progress feels satisfying.
- Example: “Complete your profile, invite a teammate, create a project.”

### Sample data

- Pre-populate dashboards with realistic data.
- Helps users understand the product before they add their own.

### Wizards

- Guide users through multi-step setup.
- Useful for complex products.
- Keep steps short and show progress.

### Empty states as onboarding

- Each empty screen is a chance to explain and guide.
- Include a clear CTA to the first action.

---

## 4. Best Practices

- **Start with value, not features.** Explain what the user can do, not every capability.
- **Minimize upfront setup.** Ask only what you need to deliver value.
- **Get to activation fast.** Reduce time-to-value as much as possible.
- **Make it skippable and resumable.** Do not force users through a wall.
- **Use real data and examples.** Abstract tours are forgettable.
- **Measure activation and iterate.** Track completion and drop-off.
- **Personalize when possible.** Tailor onboarding to the user’s goal or role.

---

## 5. Common Mistakes

- Long, mandatory product tours.
- Explaining features instead of value.
- Asking for too much information upfront.
- No clear activation metric.
- Treating onboarding as a one-time event.
- Ignoring empty states as onboarding moments.
- Not measuring drop-off.

---

## 6. Metrics

- **Time to first value**: how quickly the user reaches activation.
- **Activation rate**: percentage of new users who activate.
- **Onboarding completion**: percentage who finish the guided steps.
- **Drop-off by step**: where users leave.
- **Day 1 / Day 7 / Day 30 retention**: whether activation leads to staying.

---

## 7. Checklist

- [ ] Activation moment is defined and measurable.
- [ ] Onboarding is focused on value, not features.
- [ ] First action is clear and quick.
- [ ] Setup is minimal; advanced options are deferred.
- [ ] Tooltips and tours are skippable and contextual.
- [ ] Empty states guide users to the first action.
- [ ] Checklists or progress indicators are used for multi-step setup.
- [ ] Sample data is provided where helpful.
- [ ] Onboarding is measured and iterated.
- [ ] Users can resume onboarding later.
