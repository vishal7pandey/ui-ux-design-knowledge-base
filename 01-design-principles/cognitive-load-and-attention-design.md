# Cognitive Load and Attention Design

Cognitive load is the mental effort needed to use a product. Lower load leads to faster, more confident, and more satisfying experiences. Attention design is how we guide and protect the user’s focus.

---

## 1. Types of Cognitive Load

### Intrinsic load

The inherent complexity of the task itself. It cannot be reduced, but it can be managed.

### Extraneous load

Unnecessary mental effort caused by poor design.

- Confusing layout.
- Unclear labels.
- Too many steps.
- Unfamiliar patterns.

### Germane load

Mental effort that supports learning and understanding.

- Helpful examples.
- Clear explanations.
- Good feedback.

---

## 2. Reducing Cognitive Load

### Progressive disclosure

Show only what is needed at each step. Reveal more as the user advances.

### Chunking

Group information into meaningful units.

- 4 items are easier to scan than 12.
- Use headings, cards, and lists.

### Defaults

Pre-select the most likely choice. Reduce the number of decisions.

### Visual hierarchy

- Use size, color, spacing, and position to guide attention.
- Make primary actions obvious.
- De-emphasize secondary content.

### Consistency

- Use the same patterns for the same actions.
- Align with platform conventions.
- Reduce the need for new learning.

### Clear labels

- Use plain language.
- Avoid jargon.
- Add helper text where needed.

---

## 3. Attention Design

### Signal-to-noise ratio

Increase the ratio of useful information to decoration.

- Remove unnecessary elements.
- Use whitespace to focus attention.
- Avoid visual clutter.

### Attention hierarchy

1. What the user must see first.
2. What they should see second.
3. What they can find if needed.

### Salience

- Motion, color, and contrast draw attention.
- Use them for the most important elements.
- Do not overuse; attention is a limited resource.

### Focus

- Keep users on one primary task per screen.
- Use modals and full-screen for focused work.
- Reduce links and actions that lead away from the task.

---

## 4. Load by Screen Type

### Landing pages

- One clear value proposition.
- One primary CTA.
- Minimal friction.

### Dashboards

- Prioritize top metrics.
- Use progressive disclosure for details.
- Avoid dense grids.

### Forms

- Fewer fields at once.
- Clear labels and validation.
- Step indicators for long forms.

### Onboarding

- One concept at a time.
- Short, skippable steps.
- Show progress.

---

## 5. Performance and Perceived Load

- Faster interfaces feel easier.
- Skeletons make waits feel shorter.
- Reduce unnecessary animations.
- Show progress for long tasks.

---

## 6. Accessibility and Cognitive Load

- Use simple language.
- Provide clear structure.
- Avoid time pressure.
- Support reading and focus aids.
- Honor `prefers-reduced-motion`.
- Do not rely on memory.

---

## 7. Common Mistakes

- Too much information on one screen.
- Competing CTAs.
- Long paragraphs of text.
- Unfamiliar or inconsistent patterns.
- Too many decisions at once.
- Hidden or unclear navigation.
- Overuse of attention-grabbing effects.
- Ignoring the user’s current goal.

---

## 8. Checklist

- [ ] Each screen has one primary task.
- [ ] Content is chunked and grouped.
- [ ] Progressive disclosure is used.
- [ ] Defaults reduce decision-making.
- [ ] Visual hierarchy guides attention.
- [ ] Signal-to-noise ratio is high.
- [ ] Labels are plain and clear.
- [ ] Layout is consistent and predictable.
- [ ] Load is reduced for complex tasks.
- [ ] Attention is directed to the most important elements.
- [ ] Cognitive accessibility is considered.
- [ ] Performance supports perceived ease.
