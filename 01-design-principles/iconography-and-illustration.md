# Iconography and Illustration

Icons and illustrations help users scan, understand, and navigate. They must be clear, consistent, and meaningful. Poor iconography confuses more than it helps.

---

## 1. Iconography

### When to use icons

- To speed up scanning.
- To represent common actions or objects.
- To support navigation and labels.
- To add visual interest without clutter.

### When to avoid icons

- When the concept is abstract or unfamiliar.
- When the icon needs a label to be understood.
- When the same icon means different things in different places.

---

## 2. Icon Design Principles

### Clarity

- Use simple, recognizable shapes.
- Avoid unnecessary detail.
- Test at the size they will appear.

### Consistency

- Use the same style, weight, and size across the product.
- Use a single icon library or set.
- Maintain the same metaphor for the same action.

### Scalability

- Use vector formats (SVG).
- Ensure icons are readable at 16px and larger.
- Test on 1x and 2x displays.

### Meaning

- Choose metaphors that match real-world objects or actions.
- Pair icons with text when the meaning is not obvious.
- Avoid culturally specific or ambiguous symbols.

---

## 3. Icon Usage

| Use case | Guideline |
|----------|-----------|
| **Navigation** | Icons with labels for clarity. |
| **Actions** | Icon + label or icon-only for very common actions. |
| **Status** | Use color + icon + text; do not rely on icon alone. |
| **Empty states** | Larger, friendly illustrations. |
| **Tooltips** | Small, descriptive icon. |

---

## 4. Icon Accessibility

- Provide `aria-label` or `title` for icon-only buttons.
- Use `aria-hidden` for decorative icons.
- Ensure sufficient contrast.
- Do not rely on color or icon alone for meaning.

---

## 5. Illustration

### Purpose

- Explain a concept.
- Set tone and brand.
- Guide users in empty states or onboarding.
- Add warmth to otherwise dry interfaces.

### Best practices

- Keep illustrations focused on one idea.
- Match the brand and tone.
- Use inclusive and diverse representation.
- Avoid distracting from primary actions.
- Provide alt text that conveys meaning.

### Empty-state illustrations

- Show what the screen is for.
- Include a clear call-to-action.
- Keep the tone supportive, not decorative.

---

## 6. Common Mistakes

- Using too many icon styles.
- Using icons without labels where meaning is unclear.
- Inconsistent icon weights or sizes.
- Decorative icons without accessibility handling.
- Over-illustrating and distracting from the task.
- Using culturally narrow or stereotyped imagery.

---

## 7. Checklist

- [ ] Icons are simple, clear, and consistent.
- [ ] Icons are tested at target size.
- [ ] Icon-only controls have accessible labels.
- [ ] Status is communicated with more than just an icon.
- [ ] Metaphors are familiar and culturally neutral.
- [ ] Illustrations support the message, not distract.
- [ ] Illustrations are inclusive and on-brand.
- [ ] Alt text is provided for meaning-bearing images.
- [ ] Icon library is documented and versioned.
